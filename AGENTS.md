# AGENTS

## Commands
- build frontend: `./eggshell build-lib` (Fable)
- build backend: `dotnet build` (pass `-c "Web Debug"` or `-c "Native Debug"` for framework libs)
- format: `dotnet tool run eggshell-fmt -- <file.fs>` (install via `Meta/EggShellFmt/install.sh`)
- validate: `.agent-os/bin/agentos all`
- verify: `.agent-os/bin/agentos verify`
- done: `.agent-os/bin/agentos done`
- clean stray fable output: `.claude/skills/fable-rebuild-verify/scripts/clean-stray-fable-output.sh`
- symptom match: `scripts/symptom-match.sh "<error>"` (grep runbooks before improvising)
- status dashboard: `scripts/status-dashboard.sh`

## Invariants
- Build is green before any done claim. The compile verifier clears the Fable cache, then asserts "Started Fable compilation" is present and "error FS" plus "Skipped compilation" are absent. A stale-cache false green fails the gate.
- Framework-dependency rebuild: after editing `LibClient` or `LibRouter`, touch the changed file and confirm the app watch logs show the framework lib recompiled (not just app files). For native, use `Metro --reset-cache` when a framework change is not picked up.
- STATE.yaml is current: task_id, goal, and next_action match the active task.
- Toolchain: Fable 5 (`fable` 5.4.0, `Fable.Core` 5.0.0, `Fable.React` 10.0.0-alpha.1), .NET 10 SDK (`global.json` 10.0.301). Write Fable 5 code; do not target Fable 4.
- UI stack: React 19.2 + react-native 0.86 + react-native-web 0.21.2 (Fabric), RNGH 3. ReactXP is retired. The primitive seam is `LibClient/src/Rn/` (namespace `Rn`, prefix `Rn.`). Do not write `ReactXP` or `RX.` in new code.
- `.fs.js` are generated Fable output and git-ignored. Never commit them.
- No em-dash in prose (enforced by custom-checks em-dash-scan).
- No banned NuGet packages: Moq, AutoMapper (enforced by dependency-policy.yaml).
- Use the efficient model unless a task needs heavy reasoning.

## Forbidden
- Do not edit paths under `never` in `policies/path-policy.yaml`: `_autogenerated_`, `*.render`, `*.typext.fs`, `*.fs.js`, `node_modules`, `.build`, `.git`.
- Do not run `dotnet fable` directly (enforced by `policies/command-policy.yaml`). Use `./eggshell build-lib`, `eggshell dev-web`, or `eggshell dev-native`. Output belongs under `.build/<platform>/`.
- Do not claim done without proof. The done gate runs verifiers and refuses on any failure.
- Do not patch or copy autogenerated Render DSL. Convert to pure F# per `modernization/render-dsl-retirement.md`.

## Approval gates
- Edits under `ask_first` in `policies/path-policy.yaml` warn but do not block (`Suite*`). Claude Code shows exit 1 output as stderr but the edit still executes. The opencode plugin logs a warning. To make ask_first a true blocking gate, map it to exit 2 in the hook wrapper (Claude Code blocks only on exit 2).
- Deploy, delete, and migrate need human sign-off.
- Git pre-commit hook: after a fresh clone, run `git config core.hooksPath .githooks` to activate the committed pre-commit gate. The Claude Code and opencode hooks work without this step; only the git gate needs it.

## Scope
- may edit: `Lib*`, `Meta`, `ThirdParty`, `Fake`, `scripts`, `docs`, `AppEggShellGallery` (see `policies/path-policy.yaml`).
- ask first: `Suite*` (applications; warns but does not block in Claude Code; do not modify unless explicitly asked).
- never: `_autogenerated_`, `*.render`, `*.typext.fs`, `*.fs.js`, `node_modules`, `.build`, `.git`.
- App-specific theming, copy, and composition go in apps. Behavior and reusable layout go in `LibClient` (rule 13).

## Conventions
- Always use caveman style unless told "normal mode". Re-read `~/.claude/skills/caveman/SKILL.md` after compaction. Keep replies terse.
- Check available skills first (`.claude/skills/*`). Scan the list before reading files, running commands, or answering. Invoke a matching skill before any other action.
- Project docs live in `AppEggShellGallery/public-dev/docs/`. Read `maintaining-docs.md` (docs root) before changing docs or code. It is the single map of which docs to read or update.
- Maintain the engineering log (`knowledge-base/engineering-log.md`). Append a dated entry when you correct a wrong assumption or discover a gotcha. Write durable symptom-to-fix entries to `runbooks/troubleshooting.md`. Write to codemem via the `codemem-update` skill at the end of a session that fixed a bug or learned a gotcha.
- Codemem trust policy: act on codemem entries directly (that is the token savings). Verify against on-disk state only after the action fails. When you discover a stale entry, repair or supersede it in the same session (`memory_forget` plus rewrite via the skill). Search codemem before nontrivial work. Volatile entries get confidence 0.5 plus a date; durable invariants get confidence 0.9.
- Check runbooks before repeated work. Before any dev-loop, build, or observe task, read `runbooks/` (start at `runbooks/index.md`) and follow its commands. Fix the doc when a runbook step is wrong.
- Accessible design is mandatory. Every UI change ships accessible by default (screen readers, low vision, color contrast, motor, hearing, cognitive, motion). See `accessibility/index.md` and `accessibility/recipes.md`.
- Framework-first UI. Extend `LibClient` or `LibRouter` for reusable behavior. Keep apps to palette, theme, and domain composition. Add a gallery page for new or changed `LibClient` components.
- Read upstream issues before building third-party spikes. Use `gh issue list` and `gh issue view` (not webfetch) to check upstream repos first. Cite issue numbers in the spike catalog.
- Match surrounding conventions. Reuse, do not duplicate. Factor shared logic into one place. Build reusable tooling for repetitive conversions.
- F# formatting: 4-space indent, ~120 char soft limit, column alignment by `eggshell-fmt`. Run `dotnet tool run eggshell-fmt -- <file.fs>` after editing F#. See `AppEggShellGallery/public-dev/docs/fsharp/formatting.md`.
- Component conventions: modern pure-F# component = single `Foo.fs` using `type LC with [<Component>] static member`. No style leaks: never run `makeViewStyles` inside render. See `fsharp/styling.md`. React key warnings: use `castAsElementAckingKeysWarning` for static sibling arrays. `.fsproj` compile order matters: a component's source files precede any generated files.
- Consult Fable docs regularly. Do not guess Fable or Fable.React API. Local clone path in `knowledge-base/engineering-log.md`; otherwise https://fable.io/docs.
- Gallery mirrors converted components. When a `LibClient` component converts to pure F#, update the `AppEggShellGallery/src/Components/Content/` page. No new render DSL in the gallery.
- Vendored runtime: `.agent-os/` is a copy of agent-os v0.7.0. Run `.agent-os/bin/agentos upgrade --check` to see if an update is available, then `.agent-os/bin/agentos upgrade` to refresh. Do not hand-edit files under `.agent-os/`; the upgrade overwrites them.

## Operating procedure
- At task start, fill STATE.yaml: task_id, goal, next_action. Keep it current.
- Append one line to `evidence/ledger.ndjson` for each verified step: the claim, the proof, the timestamp.
- Before any done claim, run `.agent-os/bin/agentos all`. Every check must pass.
- To claim done, set `stop_readiness: ready` in STATE.yaml, then run `.agent-os/bin/agentos done`. A prose claim is not a done claim.
- `.agent-os/bin/agentos verify` runs the commands in `policies/verification.yaml` and writes the derived status into STATE.yaml.
- At session end, evaluate whether a project skill (`.claude/skills/*/SKILL.md`) should be updated. Promote repeatable procedures and gotchas to skills.
